# DUDE Robotic Hand Project Context

## Hardware Configuration
- Raspberry Pi Zero W
- 8x SG90 servo motors
- PCA9685 PWM controller
- Custom 3D printed hand structure

## Performance Requirements
- 50Hz servo update rate
- <5ms emergency stop response
- Battery operation (4+ hours)
- Real-time AI integration

## Safety Requirements
- Multiple bounds checking layers
- Emergency stop functionality
- Current limiting protection
- Thermal monitoring
