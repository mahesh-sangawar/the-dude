# Coding Standards - DUDE Project

## Python Standards
- PEP 8 compliance
- Type hints required
- Comprehensive docstrings
- Error handling mandatory

## Safety-Critical Requirements
- All servo functions must include bounds checking
- Emergency stop integration required
- Hardware fault detection mandatory
- Logging for all safety events

## Performance Standards
- Maximum 20ms loop execution time
- Memory usage < 100MB
- CPU usage < 50% average
