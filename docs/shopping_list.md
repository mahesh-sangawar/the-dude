# 🛒 DUDE Project Shopping List

## 🚨 **Priority 1: Essential for Professional Results**

### PCA9685 PWM Controller
- **Item**: 16-Channel 12-bit PWM Servo Driver
- **Price**: ~$10-15
- **Source**: Amazon, Adafruit, eBay
- **Why Essential**: Controls all 12 servos simultaneously with precision
- **Search Terms**: "PCA9685 servo driver", "16 channel PWM board"

### Power Supply Upgrade
- **Item**: 5V 8A Switching Power Supply
- **Price**: ~$15-20
- **Why**: 12 servos need stable, high-current power
- **Alternative**: 5V 5A minimum (budget option)

### Servo Extension Cables
- **Item**: Servo Extension Cables (Male-Female)
- **Quantity**: 12 pieces, various lengths (15cm, 30cm)
- **Price**: ~$10-15
- **Why**: Clean wiring from controller to servos

1. **Bundle orders** - Combine shipping costs
2. **Check local stores** - Avoid shipping delays
3. **Buy quality power supply** - Cheap ones cause servo jitter
4. **Start minimal** - Test before buying everything
5. **Used components OK** - Servos, controllers work fine used
